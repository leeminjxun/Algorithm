# 🔁 BOJ: 1548 부분 삼각 수열 (완전탐색 / greedy, Gold5)

https://www.acmicpc.net/problem/1548

# 풀이 과정

N개의 수로 이루어진 수열 A가 주어졌을 때, 
이 수열의 부분 수열 중 임의의 세 원소 x,y,z를 골랐을 때 **언제나 삼각형을 만들 수 있는 수열**을 '부분 삼각 수열'이라고 한다.

길이가 N인 수열 B(b[0], b[1], ..., b[n-1])의 모든 b[i], b[j], b[k]가 삼각관계에 있으면 이 수열은 삼각 수열이라고 한다.

이 때 수열 내의 임의의 수 b[i], b[j], b[k] 를 a, b, c 라 칭했을 때, a b c 의 대소관계는 다음과 같다.

a <= b <= c

또한 세 수 x, y, z가 x+y>z, x+z>y, y+z>x의 관계를 보았을 때, x <= y <= z 일 경우
x+z>y 와 y+z>x 는 무조건 참이다.
ex) x = 1, y = 1, z = 1 일 때를 생각해보자

하지만 x+y>z 는 위의 예제의 경우 참이지만, x = 1, y = 2, z = 3 일 경우 거짓이다.

우리는 주어진 수열에서 x+y>z 가 참이되는 부분 수열 중, 길이가 최대인 값을 구해야한다.

만일 1 2 3 4 5 6 과 같은 수열이 있을 때, 수열의 길이를 전체로 선택했을 경우,
1 + 2 < 6 이므로 참이 될 수 없다.

수열의 길이를 5로 줄였을 때,

2 + 3 < 6 이므로 참이 될 수 없다.

수열의 길이를 4로 줄였을 때,

3 + 4 > 6 이므로 참이 된다.

하지만 위와 같이 작은 수 부터 줄였을 때만 정답이 될수는 없다.

만약 3 4 5 6 1000 과 같은 수열이 있을 경우,

작은 수 인 3 부터 줄여도 결국 5 + 6 < 1000 이므로 해당 수열은 삼각수열이 존재하지 않는다는 결과가 나온다.

우리는 앞뒤로 둘 다 줄이는 경우를 모두 탐색해야한다.

가장 큰 값 1000 을 뺀 수열을 비교하였을 때는,

수열 3 4 5 6 이 가장 긴 부분 삼각 수열이 된다.
