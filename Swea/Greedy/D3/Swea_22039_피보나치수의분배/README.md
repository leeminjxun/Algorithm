# 📌 SWEA: 22039 피보나치 수의 분배 (greedy, D3)

# 풀이과정

해당 문제는 피보나치 수열의 성질에 대해서 이해하면 쉽게 풀 수 있다.

피보나치 수열은 기본적으로 부분합의 성질을 가지고 있다.

f(3) = 1 + 1 = 2
f(4) = 1 + 2 = 3
f(5) = 2 + 3 = 5

위처럼 더하는 두 수 f(n - 1) 와 f(n - 2) 를 B 로 두고 f(n) 을 A 로 둔다면 BBA 와 같은 문자열이 완성된다.

N == 2 :

1 1 -> 이 경우에는 BA 가 되어야한다.

N == 3 :

1 1 2 -> 이 경우에는 f3 = f2 + f1 이므로 BBA 가 된다.

N = 5 :

1 1 2 3 5 

위의 경우에는 다음과 같이 나눌 수 있다.

{1 1}, {2 3 5} -> BA BBA
