# ❌ SWEA: 4831 전기버스 (Greedy , D3)

# 풀이과정

[핵심 아이디어]
현재 위치에서 갈 수 있는 충전소 중
가장 먼 충전소로 이동한다.

⸻

버스는 한 번 충전하면 최대 K칸 이동 가능하다.

따라서 현재 위치에서:

current + K

범위 안에 있는 충전소들 중 가장 멀리 가야 이후 이동 가능성이 가장 커진다.

⸻

예를 들어:

K = 3
충전소 = 1 3 5 7

현재 위치가 0이면:

0 ~ 3 범위 이동 가능
→ 1, 3 중 가장 먼 3 선택

다음 위치 3

3 ~ 6 범위 이동 가능
→ 5 선택

매 순간 가장 멀리 갈 수 있는 충전소를 선택하는 그리디
