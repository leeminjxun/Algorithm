# ❌ SWEA: 17642 최대 조작 횟수 (Greedy , D3)

# 풀이과정

연산은 두가지 이다.

1. A 에 임의의 소수를 더한다.
2. B 에 임의의 소수를 뺀다.

위의 연산을 최대로 많이 하여 A와 B 값을 같게 만들어야한다.

그렇다면 위의 연산으로 A 와 B 값을 만들지 못하는 경우는 어떤게 있을까?

1. A가 B 보다 큰 경우
   - A 가 B 보다 큰 경우, A 는 계속해서 증가하고 B 는 계속해서 감소하므로 어떤 수를 골라도 같게 만들 수 없다.
2. A 와 B 의 차이가 양수 1 인 경우
   - 이 경우에는 A 를 한번 더 하거나, B 는 한번 빼거나 둘 중 하나를 해야하지만, 임의의 소수 중 골라야하기 때문에 최솟값 2를 더하거나 뺄 수 밖에 없다.

이외의 경우에 연산을 최대로 하여 A 와 B 를 같게 만드는 방법은 다음과 같다.

우선 B - A 로 diff 를 구한다.
diff 는 두 수를 같게 만들기 위해 필요한 수이다.

우리는 연산을 최대로 해야하기 때문에 소수 중 가장 작은 수 인 2 를 택한다.

만약 diff 가 짝수 일 경우 diff / 2 를 하여 필요한 연산의 수를 구할 수 있다.

하지만 diff 가 1보다 큰 홀 수 일 경우, diff / 2 를 해도 나머지 1이 남는다. 1은 소수에 속하지 않아 연산에 포함할 수 없다.
이때는 2 하나를 3으로 대체하면 해결된다.

if. diff = 5

2 + 2 + 1 -> 2 + 3

이 값은 짝수일 때 와 같아 diff / 2 로 통일된다.
